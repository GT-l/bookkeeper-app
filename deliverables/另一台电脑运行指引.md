# 另一台电脑运行指引

## 0. 你拿到的是什么

两个压缩包，内容完全相同（完整工程 + `.git` 提交历史 + 交互原型）：

| 文件 | 适用系统 | 解压方式 |
|---|---|---|
| `bookkeeper-app-完整工程-20261124.tar.gz` | macOS / Linux | 双击，或 `tar xzf xxx.tar.gz` |
| `bookkeeper-app-完整工程-20261124.zip` | Windows | 右键 → 全部提取 |

解压后得到 `bookkeeper-app/` 目录 —— 这就是完整工程。**用 Android Studio 打开这个根目录，不是里面的 `app/` 子目录。**

包内已含：`gradlew`（可执行）、`gradlew.bat`、`gradle-wrapper.jar`（有效）、全部 207 个 Kotlin 源文件、96 个 JUnit 用例、`BUILD.md`、`docs/`、交互原型 HTML、CI workflow、`.git`（1 个提交，origin 已预置）。

## 1. 三种「运行」方式，按需选一种

### 方式 A：零环境预览（最快，2 秒）

双击 `deliverables/记账App-交互原型.html`，用浏览器打开。

这是高保真交互原型：11 个页面、7 个统计子页、5 步导入向导、低置信度校对弹窗；「记一笔」「确认入账」「确认导入」会真实改动首页数据，深浅主题可切。

> ⚠️ 它是 HTML 预览，**不是 APK**，不参与 Android 构建。

### 方式 B：构建 APK（需要 Android 工具链）

前置条件（版本必须对齐，见 `BUILD.md`）：

- **JDK 17**
- **Android Studio**（含 **SDK Platform 35 / android-35** + Build-Tools 35.x）
- `ANDROID_HOME` 指向 SDK，或 `local.properties` 里写 `sdk.dir=/path/to/sdk`

> `compileSdk` / `targetSdk` 都是 35，**只装 34 会在配置阶段报 `Failed to find Platform SDK with path: android-35`**。

步骤：

1. Android Studio → `File → Open` → 选中解压后的 `bookkeeper-app/` 目录
2. 首次打开会自动下载 Gradle 8.9（wrapper jar 已随包提供，无需手动补）
3. 终端执行 `./gradlew assembleDebug`
4. 产物在 `app/build/outputs/apk/debug/app-debug.apk`
5. 装到手机：`adb install -r app-debug.apk`

> ⚠️ **198 个 Kotlin 源文件从未真实编译过，96 个用例从未运行过**。首次 `assembleDebug` 大概率报错（KSP 版本对齐、Room schema、Compose compiler 插件、Glance、POI 等），属预期。按 `BUILD.md` §4 的排查顺序逐项修即可。

### 方式 C：在模拟器 / 真机直接跑

在方式 B 的环境基础上，Android Studio 里选一台设备，点 ▶ Run。

## 2. 如果那台电脑已配置 Git 凭证（推荐，可直接 push）

压缩包保留了 `.git`，且 `origin` 已预置为 `https://github.com/GT-l/bookkeeper-app.git`。在解压目录执行：

```bash
cd bookkeeper-app
git push -u origin main
```

push 到 `main` 即自动触发 GitHub Actions 首次构建，去 <https://github.com/GT-l/bookkeeper-app/actions> 看结果。

- 成功 → Artifacts 下载 `bookkeeper-debug-apk`，解压得 `app-debug.apk`
- 失败（大概率）→ 下载 `build-log` 里的 `build.log` 贴回给我，我按日志逐项修源码

> 若提示 `remote origin already exists`，说明远端已在，直接 push；若地址不对，用 `git remote set-url origin <正确URL>` 修正。

## 3. 环境自检（在另一台电脑上跑一遍）

```bash
java -version                                # 需 17.x
echo $ANDROID_HOME                           # 需指向 Android SDK
ls $ANDROID_HOME/platforms/android-35        # 需存在
./gradlew --version                          # 需 Gradle 8.9
```

四项全过，再执行 `./gradlew assembleDebug`，能把编译错误控制在最小范围。
