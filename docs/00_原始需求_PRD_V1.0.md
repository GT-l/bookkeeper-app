# 记账软件产品需求文档（PRD）

文档版本：V1.0
文档用途：给 AI 开发助手使用，需求颗粒度细、逻辑完整，对标主流记账 App（鲨鱼记账、随手记、薄荷记账等），重点包含多平台账单导入能力
目标用户：个人日常收支记账用户；支持手动记账、自动导入其他记账 App 账单、银行卡 / 支付宝 / 微信账单，统计分析、预算管理、多账本管理
开发备注：本需求不指定前端后端技术栈，仅定义产品功能、交互规则、数据结构、异常逻辑、权限、导出导入规范；AI 开发可基于这份 PRD 直接拆分页面、接口、数据表

## 1. 产品概述

面向 C 端个人用户的轻量化记账应用，对标市面主流记账软件全部基础能力，同时强化跨软件账单迁移能力，支持从微信、支付宝、银行卡、鲨鱼记账、随手记等主流记账工具导出的账单文件一键导入，解决用户换记账软件、历史账单无法迁移的痛点。支持平台：先做移动端（Android/iOS），预留 PC 网页端适配能力；本地存储优先，可选云端同步。定位：简单稳定、导入兼容性强、统计清晰、无强制广告。

## 2. 用户角色

普通个人用户：唯一角色，自己管理全部账本、资产、账单；暂不支持多人共享账本（可预留二期需求）。二期可选扩展：共享账本、家庭记账，本次 V1 不做。

## 3. 核心目标

1. 支持快速手动录入收入、支出、转账账单，支持重复周期记账
2. 兼容市面主流账单导出文件，导入时自动匹配分类、账户，提供人工校对界面
3. 账户资产实时计算，自动统计余额，信用卡单独统计负债
4. 自定义收支分类、标签，适配用户记账习惯
5. 月度 / 年度预算管控，超预算提醒
6. 多维度图表：饼图、柱状图、趋势折线图
7. 本地备份 + 云端备份，支持自己导出全部账单
8. 数据隐私优先，账单数据加密存储

## 4. 整体数据基础定义

账单统一分 3 种类型：支出（钱流出）、收入（钱流入）、转账（账户 A 到账户 B，不计入收支，只变更两账户余额）。

基础字段（所有账单通用）：

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| bill_id | 唯一主键 | 是 | 系统自动生成 |
| book_id | 账本 ID | 是 | 归属哪个账本 |
| bill_type | 枚举 | 是 | 支出 / 收入 / 转账 |
| amount | 小数 (2 位) | 是 | 金额，正数；转账时转出金额 = 转入金额 |
| category_id | 分类 ID | 是 | 支出/收入分类；转账可为空 |
| tag_list | 数组 | 否 | 多个标签，最多 10 个 |
| account_from | 账户 ID | 是 | 资金流出账户 |
| account_to | 账户 ID | 转账必填 | 资金流入账户；支出=空；收入=account_from 空 |
| bill_time | 时间戳 | 是 | 账单发生时间（导入以这个时间排序，不是导入时间） |
| remark | 文本 | 否 | 备注、商家名称 |
| image_list | 图片数组 | 否 | 小票照片，最多 9 张 |
| cycle_type | 枚举 | 否 | 非周期 / 每日 / 每周 / 每月 / 每年 |
| cycle_end_time | 时间戳 | 否 | 周期结束时间 |
| source | 枚举 | 是 | manual 手动 / import 导入 |
| create_at | 时间戳 | 是 | 本条记录创建时间 |
| update_at | 时间戳 | 是 | 修改时间 |

## 5. 账号与基础设置模块

### 5.1 账号登录（可选，本地模式可免登录）
1. 本地离线模式（默认推荐）：不需登录，数据保存在设备本地；可手动备份文件
2. 云同步模式：手机号验证码登录，多端同步；登录后云端加密存储
- 支持退出登录；退出后云端不再自动同步，本地数据保留
- 忘记密码：短信验证码重置

### 5.2 基础设置页面
货币单位（默认 CNY，只改符号不做汇率换算）、日期格式、周起始日、默认账本、默认账户、默认分类、导入设置入口（账单导入映射管理）、备份管理入口、隐私设置（应用锁）、清除缓存、关于我们、版本更新。

## 6. 账本管理模块（多账本）

账本之间数据完全隔离。字段：账本 ID、名称、图标、描述、创建时间、是否默认、状态（启用/归档）。
功能：创建账本（内置模板：日常/家庭/旅行/生意）、切换账本、编辑、归档（归档后仍可查询导出，不能新增）、删除（强提醒+二次确认，删除该账本下所有账单/账户/分类/预算，不可恢复）。导入时可选择导入到当前账本或新建账本存放。

## 7. 账单录入模块（手动记账）

首页突出【+】快速记账按钮，弹出记账表单。
流程：选类型（支出/收入/转账）→ 填金额（数字键盘，两位小数）→ 选分类（分类树+搜索）→ 选账户（支出扣款/收入收款/转账转出转入）→ 选时间（默认当前）→ 标签（最多10个）→ 备注 → 添加照片（最多9张）→ 周期设置（每日/每周/每月/每年；两种模式：自动入账 / 提醒待入账(推荐)）→ 保存后立刻更新余额。
快捷能力：常用账单模板、快速复制账单、一键清空表单。

## 8. 【重点】外部账单导入模块

目标：从其他 App 导出 CSV/Excel 账单上传，解析、自动映射字段、自动匹配分类账户、预览校对、批量导入。支持来源：微信账单、支付宝账单、银行流水、鲨鱼记账 csv、随手记 csv。格式：.csv（优先）、.xlsx；V1 暂不支持 pdf、图片 OCR 导入。

### 8.1 导入整体流程（固定 5 步）
步骤1 选择来源：模式A 预设模板（微信支付/支付宝/鲨鱼记账/随手记/招商银行/工商银行/自定义文件）；模式B 自定义导入。
步骤2 上传文件：上限 10MB；格式校验、utf-8/gbk 自动识别、空文件/行数过少拒绝；只解析文本不执行脚本。
步骤3 文件预览 + 字段映射【最核心】：读第一行表头，展示前10行；每列映射到标准字段；自动映射（预设模板绑定，如【交易时间】→bill_time、【金额(元)】→amount、【收支类型】→bill_type）+ 人工手动映射（下拉选，支持跳过列）。特殊规则：正负区分收支开关（负数=支出，正数=收入）；转账默认不识别，预览页手动改；分类模糊匹配（同名优先→匹配不到则自动新建或统一映射到默认分类如"其他支出"）；账户匹配（同名自动匹配→匹配不到则新建或统一映射到默认账户）。
步骤4 账单预览校对页【必须】：每条展示解析出的时间/金额/类型/分类/账户/备注；支持单行编辑、单行跳过、批量修改分类/账户、批量跳过、筛选解析失败行（标红）。解析失败行（时间无法识别、金额为空/非数字）标红，必须处理或跳过。页面顶部统计摘要：总解析行数、有效数、失败数、跳过数、预估余额变化。
步骤5 确认导入：后台任务（上万条不卡页面），实时进度条，完成后生成导入报告（成功支出/收入/转账条数、自动新建分类/账户、失败条数+下载失败明细csv）。

### 8.2 导入规则约束
1. 去重逻辑（重中之重）：同一账本+相同交易时间(精确到秒)+相同金额+相同账户+相同备注 → 判定同一条跳过。页面开关【开启重复账单检测】默认开，关闭则强制全部导入。
2. 导入账单统一标记 source=import
3. 导入账单同等参与余额计算
4. 导入不生成周期账单，全部一次性
5. 转账识别：预设模板有"转账"标记才导入为转账；自定义文件默认不识别，需手动改

### 8.3 导入映射方案持久化
映射关系可保存为自定义模板，下次直接选用；可管理删除。

### 8.4 导入异常场景
时间格式多样（2025-10-01、10/01、2025/10/01、2025年10月1日）内置多解析器，失败标红；金额带中文符号（¥123.45、1,234.00千分位）自动清洗；金额为空标记失败；多币种V1不换算提醒核对；超大文件(>5000行)提示+后台导入。

## 9. 账单列表、详情、编辑删除

首页账单列表：按时间倒序，日期分组，日期头部显示当日收入/支出/净收支；卡片展示图标/分类/备注/时间/金额（支出红、收入绿、转账灰）/账户；下拉刷新、上拉加载更多、无限分页。
详情页：展示全部字段；操作：编辑、复制账单、删除、分享备注图片。
编辑：修改金额/分类/账户后自动重新计算余额（示例：支出100改200，零钱余额自动再扣100）。
删除：反向回滚余额，弹窗确认，可开启二次确认。导入批量账单删除单条只删本条。

## 10. 分类管理 & 标签管理

收支分类两套独立树（最多二级）。默认支出分类：餐饮、交通、住房、购物、医疗、娱乐、通讯、学习、人情、其他支出；默认收入分类：工资、奖金、红包、兼职、理财收益、其他收入。功能：新增一级/二级、改名改图标排序、删除（有账单绑定则先迁移再删）、排序。导入自动匹配这里的分类名称。
标签：扁平结构，归属当前账本，新增/改名/删除（删标签不删账单，只取消绑定），账单可多标签，报表可按标签筛选。

## 11. 预算管理（按账本独立）

月度预算（V1），两种模式：总预算（账本当月总支出上限）、分类预算（每个支出分类单独）。页面展示已支出/预算总额+进度条；超预算提醒（App红点+推送）；预算统计对比；每月1号自动重置+手动重置。转账不计入预算，只有支出消耗预算。

## 12. 资产账户管理

账户类型：现金、微信零钱、支付宝余额、储蓄卡、信用卡（负债，余额负数代表欠款）、理财账户、虚拟钱包、自定义。字段：ID、名称、类型、初始余额、图标、备注。
核心逻辑：储蓄卡/现金余额=初始+流入-流出+转入-转出；信用卡反向（支出=欠款增加，还款=欠款减少）；余额校准（输入实际余额，自动生成一条【余额调整账单】，单独标记，不计入收支统计）。
账户列表：展示名称/类型/当前余额；顶部总资产（信用卡负债扣减，展示净资产）；新增、编辑、停用（停用后不能选，历史保留）、删除（有账单则先迁移）。

## 13. 统计报表 & 图表分析

范围当前账本；时间范围：今日/本周/本月/本年/自定义。
Tab：概览（总收入/总支出/净结余/预算完成）、支出饼图（点击下钻）、收入饼图、趋势图（柱状/折线，按天/周/月）、分类明细表格、账户分析、标签统计。图表可点击下钻账单列表、可截图保存。转账不进收支统计和饼图，仅在账户流水体现。

## 14. 账单导出功能

选择账本、时间范围、格式(csv/xlsx)、可选字段勾选；导出到本地；utf-8编码带表头。

## 15. 搜索、筛选、批量操作

搜索备注/分类/标签模糊匹配；高级筛选（时间/类型/分类/账户/标签/金额区间/来源组合）；批量修改分类/账户/打标签/删除。

## 16. 备份与同步

本地备份（全账本数据包加密文件，含账单/分类/账户/图片索引，可恢复，恢复覆盖前二次确认）；云同步（登录模式增量同步，冲突以最后修改时间晚为准+弹窗选择）；自动备份开关（每天凌晨本地备份）。

## 17. 隐私安全

应用锁（数字密码/指纹/面容，退出多久自动上锁）；云存储HTTPS+AES加密；截图保护（可选Android）；不收集不必要信息，不主动上传账单除非开启云同步；导入文件只在本地解析，离线模式全程本地处理。

## 18. 通知提醒

周期账单提醒、预算超支提醒、每日记账提醒（自定义时间）；需申请通知权限，可关闭。

## 19. 异常与错误处理规范

大文件内存溢出（分片读取逐行解析）；余额计算异常（打标记+资产页提示）；数据库写入失败（提示不静默丢失）；网络异常（本地先存联网重试）；文件解析乱码（UTF8/GBK切换按钮）。

## 20. 非功能需求

性能：账单10万条内流畅，导入1万条<10s；兼容性Android 8.0+/iOS 14+；图片压缩；离线优先；UI简约干净，支出红收入绿转账灰。

## 21. 附录

附录A 标准导出表头：bill_time,bill_type,amount,category_name,account_from,account_to,tag,remark,source；示例：2026-10-01 12:30:00,支出,25.50,餐饮-午餐,微信零钱,,外卖,manual
附录B 微信账单映射：交易时间→bill_time、交易类型→bill_type、金额(元)→amount、交易对方→remark、支付方式→account_from
附录C 二期预留（V1不做）：多人共享账本、理财收益自动计算、OCR拍照识别小票、AI智能分类、债务管理、外币汇率换算、PC网页独立版
