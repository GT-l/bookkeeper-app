## 三、真机回归清单（需用户执行）

1. 我的页：切换账本后返回，确认净资产/预算数字不是上一本账本的。
2. 资产账户校准余额 → 我的页，确认本月支出没有虚增。
3. 存储排查：确认当前数据库、密钥、设置显示 🔒 且勾不上；删除一个旧日志后能看到成功提示。
4. 统计页：选「本年」，确认预算卡不再显示夸张超支；在概览页确认 📷 按钮不出现。
5. 饼图页截图一次后切到趋势页，确认相册没有多出重复图片。
6. 从首页换账本后切到统计 tab，确认图表用的是新账本数据。
7. 主 tab 互切与进详情，确认切换跟手、底栏不出现高度跳变。
