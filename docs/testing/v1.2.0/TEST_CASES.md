## 三、全局 / 全流程自测清单（需用户真机执行）

1. **升级兼容**：从已装 v1.1.0 覆盖安装 v1.2.0 → 启动时确认不闪退、旧账单数量与总余额不变。
2. **退款闭环**：记一笔支出 → 退款页关联该账单退一部分 → 首页余额增加、账单列表多一笔收入退款。
3. **报销闭环**：新增报销单 → 标记到账 → 确认余额增加且不能重复到账。
4. **债务闭环**：借入一笔 → 部分还款 → 再还清 → 债务进度 100%，每步余额方向正确。
5. **分期闭环**：建 3 期计划 → 逐期确认 → 三期金额之和严格等于总额，最后一期补齐尾差。
6. **批量闭环**：批量添加 3 笔 → 批量改账户 → 批量删除 → 每步账户余额与账单数一致。
7. **统计增强**：日历按天看金额 → 热力图看 12 个月 → 同比/环比 → 年度预算进度；确认余额校准流水没有混进支出。
8. **信用卡提醒**：设置账单日/还款日并开启 → 把系统日期调到还款日前 2 天 → 收到一条提醒，不堆积。
9. **识屏主链路回归**：触发一次自动记账 → 购买内容进备注 → 重复账单弹窗仍可让用户决定 → 余额只变一次。
10. **数据安全**：导出备份 → 删除一笔账单 → 从备份恢复 → 确认余额与账单一并恢复；查看崩溃日志入口可一键复制。
