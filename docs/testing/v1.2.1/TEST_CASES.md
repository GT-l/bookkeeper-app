# v1.2.1 测试用例

> 测试对象：v1.2.1（versionCode 4）——关于页版本介绍、无障碍健康检查与异常日志弹窗、OrangeOS 稳定运行引导、固定调试签名。
> 测试日期：2026-11-27。本机无 Android SDK / JDK / 模拟器，Compose 交互与真机保活需在设备上确认。

## 一、自动化用例

```bash
python3 scripts/verify_v1_2_1.py
```

共 **96 项**，在 v1.2.0 的 89 项基础上新增：

| 用例 | 断言 |
|---|---|
| T-SIGN-01 | `app/build.gradle.kts` 存在 `stableDebug` 签名配置 |
| T-SIGN-02 | `keystore/bookkeeper-debug.p12` 存在 |
| T-SIGN-03 | debug buildType 使用 `stableDebug` |
| T-A11Y-01 | `AccessibilityHealth` 健康检查文件存在 |
| T-A11Y-02 | `CaptureLog.force` 强制日志入口存在 |
| T-A11Y-03 | 无障碍服务连接时上报健康状态 |
| T-A11Y-04 | 关于页包含 v1.2.1 更新介绍 |

CI 仍执行 `assembleDebug` + `testDebugUnitTest`，单测统计写入 artifact 名。

## 二、逐流程走查

| 编号 | 流程 | 步骤 | 预期 | 执行方式 |
|---|---|---|---|---|
| T-UPD-01 | 关于页更新介绍 | 打开「我的 → 关于」 | 第一屏显示 v1.2.1，第二条显示 v1.2.0，不再只有 v1.1.0 | 静态 + 真机 |
| T-A11Y-01 | 系统关闭无障碍 | 先在无障碍设置开启服务，再手动关闭，回到自动化设置 | 弹窗「无障碍服务被系统关闭了」，有「复制 log」「去开启」 | 真机 |
| T-A11Y-02 | ROM 解绑服务 | 开关仍开、服务被系统解绑后打开识屏自检 | 自检项「无障碍服务开关」变红，弹窗可复制 log | 真机 |
| T-A11Y-03 | 复制 log | 点弹窗「复制 log」 | 剪贴板包含系统开关、最后连接/断开时间、机型、保活步骤、最近日志 | 真机 |
| T-A11Y-04 | 调试页入口 | 识屏自检 → 复制稳定运行说明 | 能复制 5 条 OrangeOS 保活步骤 | 真机 |
| T-A11Y-05 | 保活引导 | 自动化设置（OPPO 系机型） | 显示「稳定运行设置」，含应用详情 / 无障碍设置 / 复制说明按钮 | 真机 |
| T-SIGN-01 | 固定签名 | 安装 v1.2.1 → 再装一次同版本 | 第二次覆盖安装成功，不再报签名不一致 | 真机 |
| T-SIGN-02 | 旧版升级 | 旧 v1.2.0 → v1.2.1 | 首次仍提示签名不一致，卸载旧版后安装；之后同签名可覆盖 | 真机 |
| T-LOG-01 | 强制日志 | 关闭识屏日志，触发一次服务解绑 | 调试页仍能复制到 A11Y 解绑记录 | 真机 |

## 三、判定标准

- `python3 scripts/verify_v1_2_1.py` 退出码 0（96/96）。
- CI `assembleDebug` 与 `testDebugUnitTest` 成功，artifact 名显示 `T<n>-F0-E0-S0`。
- Release `v1.2.1-debug` 存在且 APK 可下载。
- 真机项由用户确认；未执行项不记为通过。
