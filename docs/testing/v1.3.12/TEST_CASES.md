# v1.3.12 测试用例：截屏通道恢复与自绘页面识屏

## 一、现场日志（realme RMX3888 / Android 37）

```
无障碍服务连接：true
无障碍截屏可用：false
媒体投影会话：false
最近一次识屏：两条截屏通道都不可用
✗ 读屏节点：当前页面没有可读文本（自绘页面/WebView 常见）
✗ 两条截屏通道都不可用
```

用户结论：「既不能自动识别到订单场景，也不能通过摇一摇识别到账单内容」。

## 二、根因

| 通道 | 状态 | 原因 |
| --- | --- | --- |
| 无障碍节点读屏 | ✗ 读到空 | 微信账单详情是自绘 / WebView，`rootInActiveWindow` 无文本 |
| 无障碍截屏 | ✗ 不可用 | v1.2.3 删掉了 `android:canTakeScreenshot`，`capability` 压根没注册 |
| 媒体投影 | ✗ 无会话 | Android 14+ 规则：App 重启后授权失效，且没人主动引导重新授权 |

三条路同时断，所以不管规则写得多准都识别不了。**关键证据：用户能自己截图给我看，说明微信页面没有 FLAG_SECURE —— 截图 OCR 一定可行。**

## 三、修复

1. **恢复 `android:canTakeScreenshot="true"`**
   - 免录屏授权、不受「重启后会话失效」限制
   - 崩溃风险由 `CaptureBreakerStore` 的 in-flight 熔断兜底
2. **`A11yShotOptIn` 默认开启**（旧版本默认关闭，等于这条路一直关着）
3. **节点为空时自动截图 OCR**（`scheduleScreenshotFallback`）
   - 仅支付包名内、仅节点稀疏 / 为空
   - 15 秒节流
   - 截图后仍走 `PaymentScreenRecognizer.classify`，非支付页直接丢弃
   - 提交后进入常规静默期与去重
4. **摇一摇无通道时主动引导授权**（`shouldGuideToAuth`）
   - 只在 `NO_CHANNEL` / `CHANNEL_DISABLED` 且无投影会话时触发
   - 60 秒节流，避免「取消 → 再摇 → 又弹」死循环
   - 授权成功后 `ScreenCaptureAuthActivity` 回调 `captureNow()` 自动继续识屏
5. **诊断页文案纠正**：不再把「无截屏能力」说成预期行为，改为提示「关闭无障碍服务再重开一次让能力重新注册」

## 四、用例

### 通道

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| C-01 | 重开无障碍服务后 | 诊断页「无障碍截屏通道」显示**可用** |
| C-02 | 微信账单详情（节点为空） | 自动走截图 OCR，日志出现「节点为空，转截图 OCR」 |
| C-03 | 节点为空的非支付页（如微信聊天） | 截图 OCR 后判为 UNKNOWN，不记账 |
| C-04 | 15 秒内同一页面重复触发 | 不重复截图 |
| C-05 | 无障碍截屏被熔断 + 无投影 | 摇一摇拉起录屏授权页 |
| C-06 | 用户取消授权后 60 秒内再摇 | 不再弹授权，走失败提示 |

### 识屏

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| S-01 | 摇一摇 + 微信账单详情 | 识别金额与商户，进入确认或直接记账 |
| S-02 | 自动识屏 + 微信账单详情 | 同上（15 秒内一次） |
| S-03 | 截图含 FLAG_SECURE 页面 | 黑帧检测命中，提示「页面禁止截屏」而不是脏账 |
| S-04 | 投影已授权且会话有效 | 优先用投影，不重复拉授权 |

## 五、单元/静态

- 静态：`scripts/verify_v1_3_12.py`，新增 T-1312-01 ~ T-1312-11

## 六、真机验收步骤

1. 覆盖安装 v1.3.12（同签名，账单不丢）
2. 设置 → 无障碍 → 少花点儿：**关掉再打开一次**（让 `canTakeScreenshot` 重新注册）
3. 打开「自动化设置 → 识屏自检」，确认「无障碍截屏通道：可用」
4. 微信 → 我 → 服务 → 钱包 → 账单 → 点开任意一笔 → 摇一摇
5. 若提示需要授权，允许一次录屏；之后重启 App 只需重开无障碍服务即可

## 七、边界

- 若某 ROM 上 `takeScreenshot` 直接崩进程，`CaptureBreakerStore` 会自动熔断该通道，诊断页显示「已自动停用」，点「恢复截屏通道」可再试。
- 媒体投影会话在 App 重启后必然失效，这是 Android 14+ 的系统规则，App 无法绕过；此时依赖无障碍截屏或重新授权。
- 每次覆盖安装后系统会撤销无障碍授权（日志 `source=com.android.packageinstaller revokeCount=5`），需要在系统设置里重新打开一次，或用 `scripts/android_unlock_accessibility.sh restore` 授予自动恢复。
