## 二、真机用例

### A. 重复判定（本轮重点）

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| TC-01 | 完成一笔 ¥23 支付，再完成一笔 **¥48** 的不同商户支付 | 第二笔正常自动入账，**不弹重复提醒** |
| TC-02 | 同一金额、同一商户 24 小时内再付一次 | 弹「这笔已记过，已跳过」或疑似重复轻卡片，符合预期 |
| TC-03 | 对同一笔旧账单反复识屏 3 次 | **只提示一次**，后续不再重复弹 |
| TC-04 | 页面没有金额、或只抽到「支付 / 已完成」等标题 | 直接放行不判重复，不出现重复弹窗 |
| TC-05 | 页面含「余额 ¥100 / 实付 ¥23」 | 抽到的金额是 **23 元**，不是余额 100 元 |

### B. 点击确认真正落库（本轮重点）

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| TC-06 | 触发低置信度底部轻卡片，点「记一笔」 | 账单**出现在账本里**；弹 3 秒「✓ 已自动记账」轻提示；不再出现「点了没反应」 |

| TC-08 | 万一仍失败（如数据库异常） | 弹 3 秒轻提示写明原因，不再静默吞掉 |

| 编号 | 步骤 | 预期 |

## 三、边界（如实说明）

- 未授予 `WRITE_SECURE_SETTINGS` 时，守护只能检测 + 轻提醒，不能替用户改系统开关。
- 系统反复撤销且高级保护模式开启时，App 无解得靠系统级工具（Shizuku / Shevery）锁定；本轮会把这种现场明确识别出来并提示。
- 检查更新只读取公开 Releases；系统不允许无声安装，最后一步需点系统安装器「安装」。
