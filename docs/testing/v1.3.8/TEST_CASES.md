## 四、边界与已知限制

1. 红包页若同时不含「红包 / 恭喜发财 / 拼手气」等上下文，会退化按转账收入处理——金额与方向仍正确，仅备注前缀不同。
2. 微信版本更新可能改类名；类名只作为结果页的增强信号，文案识别仍是主路径。
3. 识屏提醒依赖自动记账前台服务每 15 秒的守护检查；自动化开关关闭时不会提醒（符合预期）。
4. 电商类页面（淘宝 / 京东 / 拼多多）本版不纳入：页面结构差异大、误报风险高，待真机样本后再做。
