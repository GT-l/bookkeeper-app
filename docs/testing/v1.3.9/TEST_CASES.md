## 三、静态一致性（`scripts/verify_v1_3_9.py`）

v1.3.1 ~ v1.3.8 全量回归 + v1.3.9 九项：
整行纯数字金额、商户标签下一行、收单机构排除（分析器/识别器两侧）、
金额跳过非实付行、分组预计算、派生 getter 移除、列表行无阴影、关于页条目收敛。

## 四、边界

1. 若页面完全没有「商户全称 / 商户简称 / 收款方」等标签、也没有带后缀的商户行，商户会留空——
   这是刻意的：写错商户比不写更糟（用户还得手改）。
2. 整行纯数字金额分值最低，任何带 ¥ / 「元」/ 标签的候选都会优先；仍受「订单号 / 手机号 / 日期 / 余额」淘汰规则约束。
3. 列表性能为结构性优化（减少重复计算与阴影层），不代表低端机一定能满帧；debug 构建本身比 release 慢是系统性的。
